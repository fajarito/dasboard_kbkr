# Dashboard 12 Indikator Prioritas KBKR

Overview dashboard for Kemendukbangga — 12 indikator prioritas KBKR.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Recharts (line + donut)

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Design

Implements the Figma Overview draft: filters, 12 indicator cards, trend chart, regional coverage donut, audit checklist, and map/ranking placeholders (`data belum tersedia`).
